# ระบบวิเคราะห์และกรองข้อความร้องเรียนบริการสาธารณะ (NLP Complaint System)

### 1. แนวคิดของ Domain และความคิดสร้างสรรค์
ระบบนี้ถูกออกแบบมาเพื่อจำลองแพลตฟอร์มรับเรื่องร้องเรียนอัจฉริยะ คล้าย Traffy Fondue เพื่อช่วยหน่วยงานรัฐกรองข้อความร้องเรียน คัดแยกหมวดหมู่ปัญหาอัตโนมัติ สกัดพิกัดสถานที่เกิดเหตุ และเซ็นเซอร์ข้อมูลส่วนบุคคล (PDPA) เช่น เบอร์โทรศัพท์ หรือลิงก์สแปม ก่อนลงระบบจริง

### 2. เทคนิค NLP ที่นำมาประยุกต์ใช้
* **Regex & Cleansing**: ลบและเซ็นเซอร์เบอร์โทรศัพท์ของไทยทุกรูปแบบ และกรอง URL ทิ้งเพื่อความปลอดภัย
* **Tokenization & Normalization**: ลบคำเชื่อมภาษาไทย (Thai Stopwords) เพื่อคัดกรองเฉพาะคำสำคัญในการวิเคราะห์
* **Topic Identification**: แยกกลุ่มปัญหาออกเป็นหมวดหมู่ต่างๆ เช่น ไฟฟ้า, น้ำท่วม, ขยะ, ถนน
* **NER & Context Extraction**: สแกนหาคำบอกตำแหน่ง (ถนน, ซอย, ใกล้) เพื่อสกัดข้อมูลพิกัดออกมาอัตโนมัติ
